## Что есть в текущем UX, чего НЕТ в туториале

### 1. Follow-up чипы внутри DailyForecastCard

Когда карточка развёрнута — появляются 3 кнопки (`DailyForecastCard.tsx:142–155`):

```
"Расскажи подробнее о сегодняшней энергии"
"Что мне стоит сделать сегодня?"
"Какие транзиты активны сейчас?"
```

Туториал говорит «нажми Развернуть» — но не показывает, что внутри есть готовые вопросы. Это единственные follow-up чипы после контента в системе.

### 2. Переключатель глубины разбора

Появляется только когда выбран контакт (`Chat.tsx:1104–1144`):

```
"Углубить разбор контакта — 2 запроса за сообщение (очень длинное — 3)"
```

Чекбокс + расширяемая панель с подсказкой. Полностью отсутствует в туториале. Это ключевая платная фича, которую пользователь самостоятельно вряд ли найдёт.

### 3. Контекстные чипы (не просто «быстрые темы»)

Шаг 5 говорит «нажми тему — появится запрос». Не объясняет, что чипы **меняются** в зависимости от того, кто выбран (`Chat.tsx:752–769`):

- Я → личный разбор (5 промптов)
- Партнёр/Муж → совместимость, прогноз пары (5 промптов, gender-aware)
- Ребёнок → таланты, здоровье, общение (5 промптов, gender-aware)
- Начальник → карьера, повышение, увольнение (5 промптов, gender-aware)
- Другие → универсальные (5 промптов)

### 4. Добавление контакта (процесс)

Шаг 10 указывает на PeoplePanel и говорит «здесь добавляешь людей». Не показывает кнопку «+ Добавить» и не ведёт через процесс. `ChatOnboardingOverlay` делает это отдельно после туториала.

## Критические баги

### Баг 1: Шаг 3 сломан для залогиненных пользователей

`Chat.tsx:771–772`:

```ts
const promptSubtitle = selectedContactId == null
  ? (!isLoggedIn ? '5 бесплатных запросов...' : '')  // если залогинен — пустая строка
```

Когда пользователь залогинен → `promptSubtitle = ''` → рендерится `<p className="sr-only" aria-hidden="true">` (скрытый элемент). Туториал пытается подсветить невидимый элемент → fallback: centered tooltip без spotlight. Пользователь видит подсказку про «5 запросов» поверх пустого места — без spotlight-подсветки.

### Баг 2: Двойное объяснение PeoplePanel

- Шаг 10 туториала: объясняет PeoplePanel
- `ChatOnboardingOverlay`: объясняет PeoplePanel снова, если у пользователя нет контактов

Оба срабатывают у нового незалогиненного пользователя. Разрыв минимальный.

### Баг 3: Принудительное открытие ProfileSheet (шаги 8–9)

`Chat.tsx:549`: `if (tutorialStep === 8 && !showProfile) setShowProfile(true)`

ProfileSheet открывается автоматически без действия пользователя. Пользователь ещё не потратил ни одного запроса — а ему уже показывают «как покупать пакеты». Контекст неверный: продажа до ценности.

## Рекомендации

### Вариант А: Минимальный туториал (4 шага)

Убрать всё административное, оставить только то что ведёт к ценности:

1. **Welcome** — одна строка, без «2 минут»
2. **Forecast card** — wow-момент: персональный прогноз, упомянуть follow-up чипы внутри
3. **Starter chips** — как нажать первый вопрос
4. **PeoplePanel** — совместимость, это не очевидно

Убраны шаги: 3, 4, 6, 7, 8, 9.

**Что теряет пользователь**: знание про регистрацию и покупку пакетов заранее — не потеря, он узнает в нужный момент.

---

### Вариант Б: Оптимальный туториал (6 шагов)

Добавляет то, что реально помогает разобраться в нетривиальных фичах:

1. **Welcome** — «Покажу три фишки за 1 минуту»
2. **Forecast card** → нажать Развернуть внутри туториала, показать follow-up чипы
3. **Starter chips** — показать + упомянуть что меняются по контексту
4. **PeoplePanel** — добавить человека (направить на кнопку «+ Добавить»)
5. **Depth switcher** — «углублённый разбор» когда контакт выбран (новая фича, не очевидна)
6. **Profile** — коротко «здесь сохраняешь прогресс» (без принудительного открытия листа)

Убраны шаги: 3, 4, 6, 7, 8, 9. Логика открытия ProfileSheet — убрать принудительное.

---

### Вариант В: Если делать с нуля сегодня

**Принцип**: сначала ценность, потом объяснение — а не наоборот.

**Нулевой туториал + прогрессивное раскрытие:**

- **На старте**: автоматически подставить в инпут первый чип («Что звёзды могут сказать обо мне?») — пользователь просто нажимает «Отправить» → получает первый ответ (wow-момент) без единого шага туториала
- **После первого ответа**: появляется один маленький тултип над PeoplePanel — «Хочешь спросить про кого-то конкретного? Добавь человека сюда»
- **Когда контакт добавлен и выбран**: мини-тултип на переключателе глубины — «Можно углубить разбор — 2 запроса вместо одного»
- **При выходе или после 3-го запроса**: предложение зарегистрироваться в контексте («Чтобы не потерять эти разборы...»)
- **Forecast card**: пульсирующая точка-новинка при первом заходе, или `title` атрибут

Это заменяет 10-шаговую лекцию на 2–3 контекстные подсказки в нужный момент. Пользователь получает первый wow-момент на нулевом шаге.

## Итог

Из 10 шагов реально нужны 3–4. Шаги 3, 4, 6, 7, 8, 9 либо дублируют очевидный UI, либо административны, либо показывают «продажу» до ценности.

**Главные пропуски в туториале:**
1. Follow-up чипы в прогнозе — не упомянуты
2. Переключатель глубины разбора — полностью отсутствует
3. Контекстность стартовых чипов — не объяснена

**Главный баг:** Шаг 3 сломан для залогиненных пользователей — spotlight светит на скрытый элемент.
