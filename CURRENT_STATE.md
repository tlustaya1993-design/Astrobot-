# AstroBot — текущее состояние
_Обновлено: май 2026_

## Что работает и не трогать без необходимости

### Промпт (buildSystemPrompt)
- Иерархия методов: натал → прогрессии → соляр → транзиты
- Правило отбора сигналов (три приоритета)
- Формула интерпретации сигнала с примерами
- Натальное vs транзитное — разделение явное
- Правило смены слоя (антиповтор)
- Тревожные запросы + маскинг
- Анти-GPT-speak
- Бинарные вопросы — 1-2 реальных исхода + смежная тема
- Параллельные процессы vs альтернативные исходы
- Порядок: сначала основная часть, потом ✦-блок
- Условный крючок вместо обязательного
- Форматирование ✦-блока — каждый сигнал на отдельной строке
- **Dialog state в промпте:** блок `usedSignalsBlock` перед профилем — уже разобранные ✦-сигналы; не разворачивать повторно как основной анализ; короткая связка допустима; смена слоя (прогрессии / соляр / натал / другая планета / дом)
- **Крючок + used signals:** список разобранных аспектов не запрещает хвостик, если в профиле есть ещё не раскрытый слой по теме

### Бэкенд (dialog state)
- Колонки `conversations.used_signals_json`, `conversations.last_hook_topic`
- `artifacts/api-server/src/lib/dialogState.ts` — парсинг ✦-сигналов и крючка, дедуп (лимит 30), нормализация ключей (сокращения транз./натал./прогр., орбы, градусы)
- Чтение state перед `safeBuildSystemPrompt`; запись после успешного стрима (`updateConversationDialogState`, ошибки только в лог)
- История astro-сообщений в LLM по-прежнему заменена плейсхолдером — опора на state + свежий расчёт в system prompt

### UI
- Золотая вертикальная полоса ✦-блока через ::before
- Градиентный золотой для strong в основной части
- Градиентный золотой для strong на мобильном — класс astro-md-strong-gold с display: inline и @supports fallback
- pre-line для переносов в ✦-блоке
- Стабильный цвет ✦-блока при стриминге

## Известные ограничения — не трогать без отдельной задачи
- Мерцание и вспышка с перебросом в начало сообщения при стриминге
- Повторы при «ещё по теме» ослаблены dialog state, но модель может снова тянуть яркие транзиты в белый текст; качество зависит от дедупа и соблюдения смены слоя
